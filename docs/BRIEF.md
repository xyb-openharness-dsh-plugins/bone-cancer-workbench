# 需求起点

来源：初始化配置。用户、场景和流程是有效的SPEC互动素材；继承会话中已有明确确认，其余不能仅因配置通过校验就当成设计定稿或研究验证。

目标用户：骨原发恶性肿瘤患者与照护者（成人/AYA 为主，家长代记场景标注待补）

场景：确诊后跨医院多轮影像与化疗周期随访中，患者与家属需要把片子、化验、手术与化疗节点、功能恢复记录整理在一处

核心流程：
1. 进入后先看档案概要与最近报告
2. 记录/核对影像检查、化验指标、手术与化疗节点
3. 在随访节律与一图秀里回顾趋势并和医生讨论

完成结果：患者在随访前能一次看到最近影像/化验、当前治疗节点与下次随访要点（医生原话口径，不做判定）

初始布局选择：business-first
