# INTERACTION-DESIGN · bone-cancer-workbench(小骨宝)

版本:v0.1.0-draft · 2026-11-10 · 对齐 28 号 IP1;一级导航与页签结构

## 一、布局

- 三段外壳:原型声明条(全部模拟、未接入宿主)→ 侧栏 236px → 顶栏 + 页脚版本行。
- 顶栏三段式:左品牌+版本 chip;中一句状态说明;右主操作(资料目录→设置→大字→AI→版本→?,贴右缘)。
- 原生 AI 对话右侧面板默认 35%,可拖 25–45%,不遮业务主区;splitter 1px + 11px 热区。

## 二、一级导航(9 项,与 app.js PAGES 逐字一致)

| 导航 | key(PAGES) | 页内 Tab(SUBPAGES) | 内容 |
| --- | --- | --- | --- |
| 看板 | dashboard | —(无 Tab) | 状态卡、最近变化、整页视图入口、下一次门诊三件事 |
| 资料库 | records | 资料库 / 整理草稿/核对 / 病情档案 / 指标检测 / 病情汇总 | 上传→解析→确认→入库;原件保留 |
| 影像随访 | imaging | 影像记录 / 原件与解析 / 复查间隔 | 模态/部位/机构/报告摘录,骨癌随访核心 |
| 分期与评估 | stage | 分期档案 / 病理与分子 / 会诊与二次意见 | Enneking/AJCC 医生原文,只抄不判 |
| 治疗历程 | treatment | 治疗路径 / 手术记录 / 化疗周期 | 一次手术/一个周期=一条记录(32 号) |
| 功能与随访 | function | 功能自评 / 假体与重建随访 / 随访节律与求助 / 感受与私密记录 | 本人自述,不自动打 MSTS 分 |
| 检查与指标 | labs | 分类指标 / 化验报告表 / 口径说明 | ALP/LDH/血象分类卡+3D 翻面 |
| 病情一图秀 | timeline | 数值曲线 / 分类与事件 / 数据口径 | C1–C12 |
| 临床研究 | trials | 2026 线索 / 已收藏 / 入组问题 | 35 号四段链路 |

设置不是一级页:顶栏「设置」打开弹窗(资料目录 / 文档解析 MinerU / 临床数据库三 Tab)。

## 三、页内 Tab 与二级

- 化验页:3 Tab(分类指标 / 化验报告表 / 口径说明),深链接可回(hash view/N)。
- 一图秀:C1–C12;指标卡 3D 翻转(MT05–MT09);整页视图 A1–A10(PV_PAGES 4 页:病理报告→报告原文 / 化验记录 / 一图秀摘要);疾病概要 P1–P9(四段)。
- 资料库五 Tab 承载导入三件链路(上传→解析→候选核对→入库)。
- 影像页:列表按时间倒序;编辑入口每页 ≤1,收进「⋯ 更多」(IP6)。

## 四、AI 入口(IP10/IP11/Q14–Q19)

- 每个一级页一处「和 AI 讨论」,预写提示词携带本页关键信息(只含事实,无判定词),不代发。
- 顶栏 AI 控件位置固定;`xxx:agent-draft` 协议 preventDefault + postMessage;独立打开(file://)进本地演示面板明说「未接通」。
- ? 专供疾病概要(顶栏 data-primer-open + 看板文字按钮双入口)。

## 六、档案切换(Q9–Q13)

顶栏/看板可见切换 A(刚确诊)/B(长期随访);切换整页联动,页头显示档案名;抽查三条记录不串档;每套覆盖零条/单条/多条/缺字段/未知日期/私密项/无原件。
