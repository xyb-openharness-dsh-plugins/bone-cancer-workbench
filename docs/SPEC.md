# SPEC · bone-cancer-workbench(小骨宝)

版本:v0.1.0-draft · 2026-11-10 · M0 骨架版,M1 调研后升 v0.2 · 0 患者访谈,场景为家族基线推演
确认人/日期:待晨审追认(无人值守)。

## 一、问题、用户与最小闭环

- 用户:骨原发恶性肿瘤(骨肉瘤/软骨肉瘤/尤因肉瘤/骨巨细胞瘤)患者与照护者,成人/AYA 为主;家长代记场景标注待补。
- 输入:手工记录、报告导入(演示态为合成数据)、AI 候选(候选/预览,未接入)。
- 动作:记录影像、化验、手术与化疗周期、功能自评;核对候选。
- 输出:看板概要、一图秀趋势、最近报告表、随访节律页。
- 失败恢复:候选拒收零副作用;更正=新增版本,不裸删除。
- 成功标准:随访前一次看全最近影像/化验、当前治疗节点与下次随访要点(医生原话口径,不做判定)。

## 二、病种范围与画像

骨原发恶性肿瘤:NCCN Bone Cancer 2.2025 覆盖的骨肉瘤、软骨肉瘤、尤因肉瘤、脊索瘤等;罕见病 #36 骨巨细胞瘤(良性侵袭性)、#57 骨肉瘤挂靠。骨转移癌不覆盖。

- A 档案:刚确诊,穿刺活检刚出,记录少,分期与方案未知,多处空白。
- B 档案:确诊 2 年,新辅助化疗 3 周期 → 保肢手术 → 辅助化疗,影像 6+ 次、化验 20+ 条、功能自评多条,含私密记录与缺字段。
