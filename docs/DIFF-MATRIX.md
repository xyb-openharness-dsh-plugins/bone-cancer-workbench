## 一、差异化矩阵(场景 → 功能 → 怎么验)

| # | 场景 | 功能 | 怎么验 |
| --- | --- | --- | --- |
| 1 | 每 3 个月复查拍片,片子与报告分散在各医院,记不清哪次查了什么 | 影像检查线:模态/部位/机构/报告,与化验同看 | 档案 B 含 ≥6 次跨 ≥3 种模态影像记录;指标页与最近报告表同源 |
| 2 | 保肢/假体术后想知道功能恢复过程 | 肢体功能自评记录:只记医生原文与自评条目,不判定 MSTS 分 | 功能记录时间线可见;判定列/自动评分 0 命中 |

## 四、一级重名率(M1 实测)

cervical-workbench 一级导航(prototypes/v0.2/app.js VIEWS,12 项):看板、病情整理、我的分期、治疗历程、性与生育、放疗与长期影响、检查与指标、病情一图秀、营养支持、心理支持、复诊准备、临床研究。

本仓一级导航(INTERACTION-DESIGN §二,7 项):看板、影像、化验、治疗、功能与随访、临床研究、设置。

逐字同名项:看板、临床研究 = 2 项。重名率实测:2/7 ≈ 29%(以本仓分母)/ 2/12 ≈ 17%(以 cervical 分母),均 ≤70%,通过。
语义同域项(概念重合但命名不同):治疗↔治疗历程、化验↔检查与指标、功能与随访↔复诊准备(骨癌口径:功能自评+随访节律)。
结构保留(家族基线):236px 侧栏、五 Tab 化验页、折叠卡、一图秀、疾病概要、临床研究四段链路。
