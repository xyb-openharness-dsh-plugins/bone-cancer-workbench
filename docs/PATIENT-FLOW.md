# PATIENT-FLOW · bone-cancer-workbench(小骨宝)

版本:v0.1.0-draft · 2026-11-10 · 0 患者访谈,按家族基线推演;每节点标注信息需求,不做医疗判断

## 旅程(推演)

1. **确诊期**:穿刺活检确诊,患者面对陌生名词(骨肉瘤/软骨肉瘤…),想知道「这是哪种、严重吗」
   → 需求:疾病概要四段(只解释不判断);档案 A 空态给下一步(去记第一次影像/化验)。
2. **分期评估期**:全身影像(PET-CT/骨扫描)、化验(ALP/LDH),报告分散
   → 需求:影像线记录 + 化验线,可比组标注,「不同方法不合并」。
3. **新辅助化疗**:2–4 周期 MAP 类方案,副反应与血象记录密集
   → 需求:周期折叠卡;用药记录;血象化验趋势(不判定粒缺阈值,【待核】占位)。
4. **手术(保肢/截肢)**:手术记录、重建方式(假体/自体骨)
   → 需求:一次手术一个折叠卡;手术原文与日期。
5. **辅助化疗与功能恢复**:周期继续,肢体功能变化
   → 需求:功能自评时间线(医生原文+自评条目,不自动打分)。
6. **长期随访**:每 3 个月胸 CT(肺转移监测)+ 局部影像;焦虑集中在「会不会复发」
   → 需求:随访节律页(医生计划原话);影像间隔可视化;求助短语「若出现 X 联系 Y」占位【待核】。

## 红线

- 旅程只描述信息需求,不描述治疗决策。
- 每节点无一手引语,如实声明;改写句不冒充引语。
- 未过临床审核的阈值与求助短语一律【待核】。
