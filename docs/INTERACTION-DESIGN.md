# INTERACTION-DESIGN · bone-cancer-workbench(小骨宝)

版本:v0.1.0-draft · 2026-11-10 · 对齐 28 号 IP1;一级导航与页签结构

## 一、布局

- 三段外壳:原型声明条(全部模拟、未接入宿主)→ 侧栏 236px → 顶栏 + 页脚版本行。
- 顶栏三段式:左品牌+版本 chip;中一句状态说明;右主操作(资料目录→设置→大字→AI→版本→?,贴右缘)。
- 原生 AI 对话右侧面板默认 35%,可拖 25–45%,不遮业务主区;splitter 1px + 11px 热区。

## 二、一级导航(7 项)

| 导航 | key | 内容 |
| --- | --- | --- |
| 看板 | dashboard | 档案概要、最近报告表、导出预览 |
| 影像 | imaging | 影像检查线(模态/部位/机构/报告) |
| 化验 | labs | 指标分类卡+一图秀 |
| 治疗 | treatment | 手术与化疗周期折叠卡(32 号) |
| 功能与随访 | function-followup | 功能自评时间线+随访节律页 |
| 临床研究 | trials | 35 号四段链路 |
| 设置 | settings | 30 号设置页 |

## 三、页内 Tab 与二级

- 化验页:五 Tab(来源→核对→档案→分类指标→汇总),深链接可回(MT01)。
- 一图秀:C1–C12;指标卡 3D 翻转(MT05–MT09);整页视图 A1–A10;疾病概要 P1–P9。
- 影像页:列表按时间倒序;编辑入口每页 ≤1,收进「⋯ 更多」(IP6)。

## 四、AI 入口(IP10/IP11/Q14–Q19)

- 每个一级页一处「和 AI 讨论」,预写提示词携带本页关键信息(只含事实,无判定词),不代发。
- 顶栏 AI 控件位置固定;`xxx:agent-draft` 协议 preventDefault + postMessage;独立打开(file://)进本地演示面板明说「未接通」。
- ? 专供疾病概要(顶栏 data-primer-open + 看板文字按钮双入口)。

## 五、IP 路径清单(S1–S8 映射)

| 路径 | 场景 | 入口→步骤→产物→回首页 |
| --- | --- | --- |
| IP-S1 | S1 | 看板→读概要/报告表→看板状态更新→常驻 |
| IP-S2 | S2 | 影像→新增影像记录(表单≤6字段)→列表+1→返回 |
| IP-S3 | S3 | 化验→录指标→卡片+曲线更新→返回 |

| IP-S6 | S6 | 临床研究→双通道检索→候选线索→返回 |

每路径有可观察产物与回首页(IP4);每页有 AI 协助示例(IP10);可写实体均有 AI 候选通道,拒收零副作用(IP5);手工与 AI 同一事实层与更正链(IP9)。

## 六、档案切换(Q9–Q13)

顶栏/看板可见切换 A(刚确诊)/B(长期随访);切换整页联动,页头显示档案名;抽查三条记录不串档;每套覆盖零条/单条/多条/缺字段/未知日期/私密项/无原件。

## 七、响应式与无障碍

30 号三档断点;数字键盘组件(IP7);a.skip 跳主区;#main tabindex=-1;aria-current;折叠用原生 details;图表 role="img";无裸删除,全站无「不可恢复」文案(IP8)。
