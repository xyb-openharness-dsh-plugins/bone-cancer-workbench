## 一、差异化矩阵(场景 → 功能 → 怎么验)

| # | 场景 | 功能 | 怎么验 |
| --- | --- | --- | --- |
| 1 | 每 3 个月复查拍片,片子与报告分散在各医院,记不清哪次查了什么 | 影像检查线:模态/部位/机构/报告,与化验同看 | 档案 B 含 ≥6 次跨 ≥3 种模态影像记录;指标页与最近报告表同源 |
| 2 | 保肢/假体术后想知道功能恢复过程 | 肢体功能自评记录:只记医生原文与自评条目,不判定 MSTS 分 | 功能记录时间线可见;判定列/自动评分 0 命中 |
| 3 | 化疗周期与手术节点穿插,记不住到哪一步 | 治疗折叠卡以「一次手术/一次化疗周期」为单元(32 号) | 档案 B 含 ≥3 化疗周期折叠卡;收展态截图 |
| 4 | 骨肉瘤肺转移率高,复查焦虑集中在胸 CT | 随访节律页:医生已确认计划原话,阈值【待核】 | 随访页存在;求助短语为医生原话式占位,无「你已进入 Z 期」式判定 |

| 维度 | cervical | 本仓 | 差异处理 |
