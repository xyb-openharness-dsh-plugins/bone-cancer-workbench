# DEV-REQUIREMENTS · bone-cancer-workbench(小骨宝)

版本:v0.1.0 · 2026-11-10 · 无人值守夜班撰写,待晨审追认
适用语境:骨原发恶性肿瘤(骨肉瘤/软骨肉瘤/尤因肉瘤等,NCCN #54;罕见病 #36 骨巨细胞瘤、#57 骨肉瘤挂靠)患者工作台。
反例边界:不覆盖骨转移癌(乳腺癌/前列腺癌骨转移属各原发仓)、不做治疗决策、不做复发概率预测。

## 一、患者视角红线

- 功能按患者关心的信息维度组织:片子在哪、化验怎么变、手术与化疗到哪一步、功能恢复如何、下次复查查什么。
- 医生任务(分期决策、方案制定、疗效判定)冒充患者需求,独立评审一票否决。
- 本仓 **0 患者访谈**(2026-11-10 夜班,无人值守):场景与功能线按家族基线推演,一手引语为 0,改写句不冒充引语。每条功能线标注「推演,待访谈」。
- 0 临床审核:所有阈值、求助短语为【待核】占位,不得写成已审核。

## 二、硬性要求(家族基线)

1. 原型是唯一视觉与交互基准;开发版逐项对齐(public 与原型逐字符 ui-parity)。
2. 两套合成演示档案(A 刚确诊记录少 / B 长期随访发作多),唯一源,切换整页联动,标注合成示例。
3. 隐私三出口(看板/导出/AI 上下文)共用同一过滤函数;私密记录及其改写问题一律排除。
4. 无判读列:数据库无 diagnosis、risk_level 等派生判定;分级徽章写「对照 CTCAE v<版本> · N 级」并带免责。
5. AI 输出永远是候选/预览;演示态明说未接入宿主。
6. 页签走查、探针(--url 显式指向本仓 prototypes/v0.2)、禁词残留 grep 全部留数。

## 三、非目标

- 不接入真实病历数据(演示态合成数据,标注「合成示例/未连接宿主」)。
- 不提供医学解读;「仅回顾,不解读」「解读归医生」同屏。
- 不做骨转移癌、不做转移瘤鉴别诊断工具。

## 四、验收总口径

npm run check 全绿;npm test 全过;audit 数字照抄;闸口逐项实测四态(通过/失败/跳过/待人工)。

## 五、可回退默认值(无人值守,晨审追认)

| 项 | 默认值 | 回退为 |
| --- | --- | --- |
| 服务主体 | 骨原发恶性肿瘤患者与照护者(成人/AYA 为主) | 用户晨审改定义 |
| 病程覆盖 | 确诊(穿刺活检)→ 围手术期 → 辅助化疗 → 长期随访 | 仅随访段 |

## 六、禁词与残留

- 前病种词(心包/CRP/effusion/冷凝集素/AML 等)全站 0 命中;跨仓语义残留由独立评审扫描。
- 非本族语义(血液肿瘤 MRD/粒缺/缓解期天数)不得出现;肿瘤分期与治疗线序语义允许(NCCN #54 为实体瘤线)。
